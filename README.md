# UniVic

App del semestre (media buying Skalers, inglés y checo): malla, horario diario, evaluaciones y avance. Pensada para instalarse en el iPad.

**Abrir:** https://thorvicc02.github.io/univic/

## Instalar en el iPad

1. Abre el enlace en Safari (no en Chrome ni desde un atajo).
2. Toca **Compartir**.
3. Elige **Agregar a pantalla de inicio**.
4. Confirma el nombre **UniVic**.

El progreso (clases, asistencia y notas) se guarda en este dispositivo.

Para estudiar inglés y checo con ejercicios, abre [Inglés de Trabajo](https://thorvicc02.github.io/ingles-trabajo/).
